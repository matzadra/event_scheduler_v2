# Event Scheduler V2

A modern event scheduling system built with cutting-edge technologies, reimagined from the **Event Scheduler** with a fresh stack and enhanced capabilities.

## Features

- Create, edit, delete, and view events.
- Prevent overlapping events with smart validations.
- Invite users to events and manage RSVPs.
- Responsive design for a seamless user experience.

## Tech Stack

- **Frontend**: Next.js, Tailwind CSS
- **Backend**: Supabase, Redis
- **Hosting**:
  - Frontend on Vercel
  - Backend using Supabase + Redis
